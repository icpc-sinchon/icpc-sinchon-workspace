# 본대회 정보

- 13문제 내외가 출제되었습니다. A번은 가장 쉬울 것으로 예상되는 문제이며, 나머지 문제의 순서는 난이도 순이 아닙니다.
- DOMJudge를 자체적으로 사용합니다. 링크는 contest.icpc-sinchon.io입니다.
- 각 **팀**은 노트북 1대로만 문제를 해결할 수 있습니다. 모든 팀은 노트북과 충전기를 지참하여야 합니다.
    - 외에 키보드와 마우스를 각각 최대 한 개씩 지참하여 사용할 수 있습니다.
- 한 팀당 A4 단면으로 인쇄된 25페이지 이내의 팀 레퍼런스 문서를 참고할 수 있습니다. 형식과 제한에 대해서는 아래를 참고해 주세요.
- 참가팀은 대회 중 코드 인쇄를 요청할 수 있습니다. 너무 많은 양의 코드 인쇄를 요청하는 경우 인쇄가 거절될 수 있습니다.
- 스코어보드는 대회 종료 1시간 전에 프리즈됩니다.

# Dify Hackathon 정보

- 본대회와 달리 개인 대회입니다. 본 대회의 팀 구성과 무관하게 개인 단위로 참가하고, 결과물도 개인 단위로 제출하시게 됩니다.
- **인터넷 검색과 AI 도구를 자유롭게** 사용하실 수 있습니다.
- 각 **참가자**는 노트북 1대로만 문제를 해결할 수 있습니다. 각 참가자는 자신이 사용할 노트북과 충전기를 지참하여야 합니다.
    - 외에 키보드와 마우스를 각각 최대 한 개씩 지참하여 사용할 수 있습니다.
- Dify Hackathon은 총 상금 30만원이며, 1등부터 3등 수상자에게 상금이 지급됩니다.
    - 공식/비공식 여부와 상관 없이 상금을 받으실 수 있습니다.
- 예비소집 및 본대회 문제를 읽어보는 것이 해커톤에 도움이 될 수 있습니다.
- 자세한 내용은 해커톤 참가자에게 발송된 메일을 참고해주시기 바랍니다.

# 본대회 규칙

## 등록

- 팀원이 모두 와야 등록할 수 있습니다.
    - 등록 이전에 대회장에 입장해 기다릴 수 있습니다.
- 이름과 사진을 포함한 신분증(주민등록증, 운전면허증, 학생증 등)을 지참하여야 합니다.
- 팀 레퍼런스 문서를 지참하는 경우 등록 시 지참하여야 합니다.

## 팀 레퍼런스 문서

- 레퍼런스 문서는 단면 A4 페이지를 표지 포함 최대 25쪽까지 지참할 수 있습니다. 출력된 형태의 문서만 지참할 수 있으며, 동일한 문서를 최대 3권(즉 75페이지)까지 지참할 수 있습니다.
- 팀 레퍼런스 문서는 등록 시 검사하며, 반려 시 지참할 수 없습니다.
- 인쇄된 글자가 너무 작거나(<2mm, 약 6pt) 다른 팀이 육안으로 내용을 읽을 수 있을 정도로 큰 경우 반려될 수 있습니다.
- 표지를 포함한 모든 페이지에는 페이지 번호가 인쇄되어 있어야 합니다.
- 팀 레퍼런스 문서는 대회 중에 파일 형태로 열람할 수 없습니다. 대회장에서 레퍼런스 문서를 출력해드리지 않습니다.

## 언어 레퍼런스 문서

언어별로 다음과 같은 레퍼런스 문서는 대회 중에 접속해 사용할 수 있습니다.

- C/C++: [https://en.cppreference.com/w/](https://en.cppreference.com/w/)
- Java: [https://docs.oracle.com/en/java/javase/index.html](https://docs.oracle.com/en/java/javase/index.html)
- Python: [https://docs.python.org/3/](https://docs.python.org/3/)

## 프로그래밍 도구

- 문제풀이에 사용되는 코드는 대회 시간에 작성되어야 합니다.
    - 팀 레퍼런스 문서의 코드를 따라 칠 수 있습니다.
    - 레퍼런스 문서의 코드를 복사해 사용할 수 있습니다.
    - 미리 작성된 템플릿 코드나 Atcoder Library 등, 미리 작성된 코드는 사용할 수 없습니다. 이는 제출하는 코드에 한정되지 않으며, 코드를 테스팅하기 위해 작성하는 코드를 포함합니다.
- Github Copilot, lex, yacc 등의 코드 생성 플러그인은 사용할 수 없습니다.
    - LSP-Clangd, IntelliSense 등의 자동완성 프로그램은 사용 가능합니다.
- ChatGPT를 비롯한 생성형 AI는 사용할 수 없습니다.
- 코드 작성과 관련되지 않은 기타 도구(단축키를 사용하여 컴파일, 입력의 파이프라인, Unix의 `diff` 등 코드의 단순 비교 등)는 사용 가능합니다.
    - Code Runner, Competitive Programming Helper 등은 사용 가능합니다.
- 관련 기타 문의사항이 있는 경우 아래의 카카오톡 채널을 통해 문의해주세요.

## 언어 및 채점

- 사용 가능한 언어는 다음과 같습니다:
    - C: C17, GCC 13.3.0
    - C++: C++20, G++ 13.3.0
    - Python: Python 3.11.15 (PyPy 7.3.23 with GCC 10.2.1)
    - Java: Java 17, OpenJDK 21.0.11
- C++으로 모든 문제를 해결할 수 있음을 보장합니다. 다른 언어로는 문제의 해결 가능성을 보장하지 않습니다.
